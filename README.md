# نقشه تعاملی استان‌های ایران

بنر سه‌بعدی تعاملی با پس‌زمینه آئورا (WebGL/CSS) و نقشه ایران که با کلیک روی استان‌های مهم، اطلاعات آن استان (تعداد سازنده و تعداد قطعه) را نمایش می‌دهد.

فایل اصلی: `Interactive 3D Banner.dc.html` — تمام کد (تمپلیت + منطق) در همین یک فایل است.

## نحوه تغییر لیست استان‌های «مهم» (قابل کلیک)

در همان فایل، دنبال آبجکت `PROVINCE_META` بگردید (نزدیک ابتدای بخش `<script data-dc-script>`):

```js
const PROVINCE_META = {
  AR: { name: 'اردبیل', important: false },
  ES: { name: 'اصفهان', important: true },
  ...
};
```

- کلید هر ردیف، کد HASC استان (مثل `AR`, `ES`, `TH`) است که از فایل نقشه (`iran_topo.json`) می‌آید.
- `name`: نام فارسی استان که روی نقشه و در کارت اطلاعات نمایش داده می‌شود.
- `important`:
  - `true` → استان روشن‌تر و درخشان‌تر رسم می‌شود، با ماوس هاور روی آن نام و آماری نمایش داده می‌شود و با کلیک، کارت آمار (سازنده/قطعه) باز می‌شود.
  - `false` → استان کم‌رنگ‌تر (خاکستری-آبی تیره) رسم می‌شود، فقط با هاور نامش نمایش داده می‌شود اما **کلیک روی آن هیچ کاری نمی‌کند** و آماری ندارد.

برای افزودن/حذف یک استان از لیست مهم‌ها، فقط کافیست مقدار `important` همان ردیف را تغییر دهید.

کدهای HASC استان‌ها (۳۰ استان؛ تهران و البرز در این نسخه از نقشه یکی هستند):

```
AR اردبیل        BS بوشهر           CM چهارمحال و بختیاری   EA آذربایجان شرقی
ES اصفهان        FA فارس            GI گیلان                GO گلستان
HD همدان         HG هرمزگان         IL ایلام                KE کرمان
BK کرمانشاه      KZ خوزستان         KB کهگیلویه و بویراحمد  KD کردستان
LO لرستان        MK مرکزی           MN مازندران             KS خراسان شمالی
QZ قزوین         QM قم              KV خراسان رضوی          SM سمنان
SB سیستان و بلوچستان  KJ خراسان جنوبی   TH تهران            WA آذربایجان غربی
YA یزد           ZA زنجان
```

## نحوه تغییر اطلاعات آماری هر استان (تعداد سازنده / تعداد قطعه)

فعلاً این اعداد **نمونه (placeholder)** هستند و به‌صورت خودکار و ثابت از نام استان ساخته می‌شوند (تابع `hashRange` در همان فایل):

```js
const makers = hashRange(meta.name + 'm', 6, 140);   // تعداد سازنده: بین 6 تا 140
const parts  = hashRange(meta.name + 'p', 300, 9000); // تعداد قطعه: بین 300 تا 9000
```

برای گذاشتن داده واقعی، این دو خط را با یک منبع داده واقعی جایگزین کنید، مثلاً یک آبجکت ثابت:

```js
const REAL_DATA = {
  ES: { makers: 84, parts: 5200 },
  TH: { makers: 120, parts: 8100 },
  // ...
};
...
const makers = REAL_DATA[id]?.makers ?? 0;
const parts  = REAL_DATA[id]?.parts ?? 0;
```

(`id` همان کد HASC است که چند خط بالاتر در تابع `loadMap()` محاسبه می‌شود.)

## سایر بخش‌های قابل تغییر

- **عنوان بالای نقشه**: تگ `<h1>` در ابتدای تمپلیت — متن را مستقیم عوض کنید.
- **رنگ‌بندی نقشه**: گرادیان‌های `glassImportant` / `glassDim` در `<defs>` و متغیرهای `strokeBase` در تابع `loadMap()`.
- **رنگ نوارهای آماری**: در بخش پاپ‌آپ، دو گرادیان سبز (سازنده) و قرمز (قطعه).
- **داده نقشه**: فایل `iran_topo.json` (TopoJSON استان‌ها) داخل همین HTML به‌صورت `<script type="application/json" id="iran-topo-data">` جای‌گذاری شده تا نقشه بدون نیاز به اینترنت/سرور هم لود شود؛ فقط کتابخانه‌های d3 / topojson-client / gsap از CDN لود می‌شوند.
